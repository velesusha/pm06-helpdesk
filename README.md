# ПМ.06 Help Desk

Учебный веб-стенд для регистрации и сопровождения заявок ИТ-службы колледжа. Сервер написан на Python, интерфейс — на HTML, CSS и JavaScript. Для локального показа используется SQLite. В папке `sql` находятся скрипты для стенда с Microsoft SQL Server.

## Запуск

1. **Windows x64**. Распакуйте весь архив проекта и дважды нажмите `START-WINDOWS.bat`. В архив входит переносимый Python 3.12.10. При скачивании исходников из Git нужен установленный Python 3.9 или новее.
2. **macOS**. В распакованной папке запустите `START-MAC.command`. Если Finder не открывает скрипт, откройте Терминал в папке проекта и выполните `bash START-MAC.command`. Нужен Python 3.9 или новее с модулем SQLite.
3. Откройте [http://localhost:8096](http://localhost:8096) и оставьте окно сервера открытым. Для остановки нажмите Ctrl+C.

Первый запуск создаёт SQLite-базу в `data` и загружает восемь учебных заявок. Данные сохраняются между запусками. Чтобы показать первый и повторный импорт вручную, запустите `python3 app.py --http --port 8096` или `py -3 app.py --http --port 8096` без параметра `--seed` и с отдельным пустым каталогом данных в переменной `HELPDESK_DATA`.

### Учебные учётные записи

| Логин | Действия |
| --- | --- |
| `operator` | Создаёт заявки, назначает исполнителей, проверяет и закрывает выполненные заявки |
| `engineer` / `engineer2` | Открывает назначенные ему заявки, берёт в работу и фиксирует решение |
| `admin` | Ведёт пользователей и категории, открывает журнал действий |

Учебный пароль для этих четырёх учётных записей — `Practice2026!`. Сервер слушает только локальный адрес 127.0.0.1.

## Демонстрация

1. Под оператором выполните поиск заявки 1001. Откройте карточку и проверьте критический приоритет.
2. Создайте заявку «Не работает принтер в кабинете 201» и назначьте исполнителя.
3. Войдите как исполнитель, возьмите заявку в работу и отметьте её решённой.
4. Войдите как оператор, закройте решённую заявку и проверьте пять событий в истории.
5. Под администратором в разделе пользователей и категорий найдите категорию «Сеть». Очистите поиск, чтобы вернуть весь справочник.

## HTTPS

Создайте окружение командой `python3 -m venv .venv` и установите пакет `cryptography` через `.venv/bin/python -m pip install cryptography`. На Windows используйте `py -3 -m venv .venv` и `.venv\Scripts\python.exe -m pip install cryptography`.

На macOS запустите `START-MAC-HTTPS.command`. На Windows выполните `.venv\Scripts\python.exe app.py --seed --port 8443`. Адрес — [https://localhost:8443](https://localhost:8443). Сертификат создаётся для локального стенда. Для проверки HTTPS передайте HTTP-клиенту публичный сертификат `data/certs/localhost.crt` как доверенный для конкретного запроса.

## Сопровождение и проверка

- `python3 -m unittest discover -s tests -v` — 21 тест на отдельной базе. На Windows используйте `py -3` вместо `python3`.
- `python3 tools/verify_upgrade.py` — проверка обновления с тега `v1.0`; требуется рабочий Git-репозиторий с историей.
- `python3 maintenance.py backup` — SQLite-копия, контрольный CSV и SHA-256. Три файла создаются в `data/backups`.
- `python3 maintenance.py restore --file <путь_к_копии.db> --target-dir <новый_каталог>` — перенос в отдельный каталог. Для проверки запуска укажите этот каталог в `HELPDESK_DATA`.
- `docs/database.svg` — схема данных. `sql/schema_sqlserver.sql` — создание структуры SQL Server. `sql/backup_restore.sql` — резервирование и восстановление в отдельную базу средствами SSMS.
- Для подключения SQL Server создайте базу `Pm06Helpdesk`, установите Microsoft ODBC Driver и пакет `pyodbc`, задайте строку подключения в `HELPDESK_SQLSERVER` и запустите `app.py` вручную. Начальная загрузка следует параметру `--seed`. Пробное восстановление выполняется в `Pm06Helpdesk_Restored`; перед запуском приложения переключите строку подключения. Пароли подключения храните в локальном окружении.

Локальный сервер предназначен для учебной демонстрации. GitHub хранит исходники и версии приложения. Для работы с заявками запускайте сервер указанным выше способом.
